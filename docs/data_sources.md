# Data Sources

## Sales Data (`sample_sales.csv`)

The core dataset contains 12 months of historical sales for 75 SKUs across 3 stores.

### Format
```csv
date,sku_id,store_id,quantity_sold,price,cost
2025-05-01,SKU_001,STORE_001,30,2.50,2.00
2025-05-02,SKU_001,STORE_001,35,2.50,2.00
...
```

- **date**: Transaction date (YYYY-MM-DD)
- **sku_id**: Stock Keeping Unit identifier (e.g., `SKU_001`)
- **store_id**: Store identifier (e.g., `STORE_001`)
- **quantity_sold**: Units sold (non-negative integer)
- **price**: Retail selling price (AUD)
- **cost**: Unit cost to retailer (AUD)

### Generation

Generated by `scripts/generate_sample_data.py` using realistic patterns:
- Base demand per SKU randomly assigned (20–80 units/day).
- Seasonal multipliers (higher demand in summer for ice cream, cold drinks; higher in winter for hot products).
- Weekend effects (increased sales for snacks and beverages).
- Store-specific scaling factors.
- Random Poisson-distributed daily variation.

Total records: ~82,000 covering 2025-05-01 to 2026-04-30.

## SKU Metadata (`sku_metadata.json`)

Contains product attributes critical for replenishment.

```json
{
  "SKU_001": {
    "name": "Milk 2L Full Cream",
    "category": "Dairy",
    "supplier": "Metcash",
    "lead_time_days": 2,
    "reorder_point": 30,
    "unit_cost": 2.00,
    "selling_price": 2.50,
    "min_order_quantity": 10,
    "shelf_life_days": 14,
    "bulk_discounts": {"50": 0.05, "100": 0.10},
    "is_seasonal": false,
    "perishable": true
  }
}
```

**Fields**:
- `name`: Human-readable product name.
- `category`: Product category (e.g., Dairy, Bakery, Beverages).
- `supplier`: Primary supplier (Metcash, PFD Food Services, etc.).
- `lead_time_days`: Expected delivery lead time from supplier.
- `reorder_point`: Stock level that triggers replenishment order.
- `unit_cost`: Cost per unit (AUD).
- `selling_price`: Retail price (AUD).
- `min_order_quantity`: Minimum order quantity enforced by supplier.
- `shelf_life_days`: Days until product expires (perishability flag).
- `bulk_discounts`: Threshold-quantity to discount-rate mapping.
- `is_seasonal`: Boolean indicating seasonal demand patterns.
- `perishable`: Boolean indicating short shelf life.

## Australian Holidays & Events (`australian_holidays.json`)

Pre-loaded public holidays and retail-specific events for 2025-2026.

```json
{
  "2025": [
    {"name": "Christmas Day", "date": "2025-12-25", "type": "public", "impact": "very_high"},
    {"name": "AFL Grand Final", "date": "2025-09-27", "type": "sporting", "impact": "high", "categories": ["Beverages", "Snacks"]},
    ...
  ]
}
```

**Fields**:
- `name`: Holiday/event name
- `date`: Date (YYYY-MM-DD)
- `type`: public / sporting / shopping / school
- `impact`: low / medium / high / very_high (used for demand uplift)
- `categories`: optional list of product categories affected
- `end_date`: optional for multi-day events

## Promotions (`promotions.json`)

Promotional periods with discount rates.

```json
{
  "2025": [
    {
      "sku_id": "SKU_001",
      "name": "Black Friday",
      "start_date": "2025-11-24",
      "end_date": "2025-11-30",
      "discount_rate": 0.30,
      "type": "percentage"
    }
  ]
}
```

The Demand Forecaster incorporates promotion flags and applies uplift multipliers.

## Weather Data (Mock BOM)

Generated synthetically by `fetch_weather_data()` with:
- Daily average temperature based on Australian seasonal patterns.
- Rainfall on ~20% of days (1–30mm).

In production, replace with real Bureau of Meteorology API calls.

## Data Validation

All data files are validated:
- **Sales CSV**: required columns, date parsing, non-negative quantities.
- **JSON metadata**: structure and required keys.
- **External data**: date range consistency.
